# Shorab Ali: engineering portfolio

Plain HTML, CSS and JavaScript. No build step.

## Put it online (GitHub Pages)
1. Create a repository named `YOUR-USERNAME.github.io` (public).
2. Upload everything in this folder (keep the folder structure).
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Open https://YOUR-USERNAME.github.io after a minute.

## Edit
- Text: `index.html`
- Colours: the variables at the top of `css/style.css`
- Photo: replace `assets/img/shorab.jpg`
- CV: replace `assets/Shorab_Ali_CV.pdf`
- The four drawings in `assets/img/` are schematics. Swap in real photos of your work when you have them.
